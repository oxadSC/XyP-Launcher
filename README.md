# XyP Launcher (Capacitor)

Мобильный лаунчер для Minecraft Bedrock. Интерфейс на чистом HTML/CSS/JS, нативная часть через Capacitor.

## Что делает

| Действие | Как работает |
|---|---|
| Скачать | `Filesystem.downloadFile` скачивает файл по URL из `versions.json` в папку приложения (`Android/data/app.xyp.launcher/files/xyp/versions/`). Сначала в `.part`, после проверки размера переименовывается |
| Проверка файла | `Filesystem.stat` при запуске и при возврате в приложение. Файл есть и размер совпал: версия считается скачанной |
| ИГРАТЬ (версия не установлена) | `FileOpener.open` открывает системный установщик Android для скачанного `.apk` |
| ИГРАТЬ (версия установлена) | `AppLauncher.openUrl('com.mojang.minecraftpe')` запускает оригинальный Minecraft. Если указан сервер, открывается `minecraft://connect?serverUrl=...&serverPort=...` |
| Удалить файл | `Filesystem.deleteFile` |

## Как собрать APK с телефона (через GitHub)

1. Создайте репозиторий на GitHub и загрузите в него все файлы из этой папки (включая скрытую `.github`).
2. Откройте вкладку **Actions**, выберите **Build XyP Launcher APK**, нажмите **Run workflow**.
3. Когда сборка закончится, скачайте артефакт `xyp-launcher-debug-apk`, распакуйте и установите `app-debug.apk`. Android попросит разрешить установку из этого источника.

Сборка на компьютере: `npm install --legacy-peer-deps`, `npx cap add android`, `node scripts/patch-android.mjs`, `npx cap sync android`, затем откройте папку `android` в Android Studio.

В `package.json` стоят версии `latest`. Если сборка падает из-за несовместимости плагинов, закрепите одну мажорную версию Capacitor и подходящую версию `@capacitor-community/file-opener`.

## Список версий

В настройках укажите адрес `versions.json` (только `https://`). Формат смотрите в `versions.example.json`:

```json
{ "versions": [ { "id": "1.21.40", "type": "release", "size": 123456789, "url": "https://...", "note": "..." } ] }
```

`size` в байтах. Если указан, лаунчер сверяет размер скачанного файла. Ссылки на файлы Minecraft в проект не включены: используйте только файлы, которые вы вправе скачивать и устанавливать.

## Ограничения Android

- Нельзя поставить версию ниже установленной, не удалив игру. Удаление стирает данные приложения, поэтому сначала скопируйте мир.
- Подпись `.apk` должна совпадать с установленной игрой, иначе установка не пройдёт.
- Лаунчер не меняет и не обходит проверку лицензии Google Play. Нужна игра, купленная на вашем аккаунте.
- Определить установленную версию Minecraft лаунчер не может, поэтому отметка «Установлено» ставится после открытия установщика. Кнопка «Установить заново» сбрасывает её.
- Нативное скачивание нельзя отменить и продолжить после обрыва: при ошибке файл скачивается заново.

## iOS

Файлы `.apk` на iOS не устанавливаются. Лаунчер там только открывает уже установленный Minecraft по схеме `minecraft://`. Чтобы это работало, после `npx cap add ios` добавьте `minecraft` в `LSApplicationQueriesSchemes` в `Info.plist`. Эту часть я не проверял.

## Проверено / не проверено

Код проверен только на синтаксис. На устройстве и в CI он не запускался. Схема `minecraft://connect` и поведение плагинов на вашей версии Android требуют проверки.
